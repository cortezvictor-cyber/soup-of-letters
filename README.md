# soup-of-letters
creacion de sopa de letras

Este Codigo ayuda a la creacion de sopa de letras por medio de las clases 
Sopa objetos se encarga de la creacion del tablero el cual contendra las palabras y la matriz 
sopa de letras lee las palabras y las dirije a las 8 direcciones de manera aleatoria y valida que no choquen las palabras

Al igual permitiendo el acceso a la cuadricula creando una copia de ella
